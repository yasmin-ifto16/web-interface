Disciplina: Introdução a Construção de Páginas Web

Atividade 1: Minha Primeira Página Web

Essa atividade, feita na Aula 2, teve no intuito de colocar em prática as primeiras tags ensinadas a nós: tags H (de 1 até 6), p, img, pre e br. Teve que incluir pelo menos 2 ocorrências de cada uma dessas tags.
O tema era livre, então falei sobre o jogo Angry Birds 2.

Atividade 2: Links

Lançada na Aula 3, tivemos que criar um site temático em HTML contendo pelo menos 4 páginas que permitam uma navegação entre elas. O tema foi livre.
Tendo que conter imagens e utilizar as tags:p, a, img, h1, h2 e manipular os atributos dessas tags de forma que possam exemplificar o aprendizado do estudante.
O meu tema livre foi: Os Planetas Gasosos

Atividade 3: Web Site hospedado em provedor gratuito

Lançada na Aula 4, o estudante teve que criar um site em alguma hospedagem.
Se está vendo isso, significa que essa atividade foi comprida com sucesso. (Oi, fessô!)
Não tivemos que criar nada em espécifico, além de colocar os links das atividades feitas na página inícial.

Atividade 4: Formatação de elementos HTML

Também conhecido como atividade do CINEMA

Lançada na Aula 5
Construimos um site com o tema: Cinema. Podiamos escolher um filme e fazer um site com este tema. Poderia ser um clássico, como "Top Gun - Ases Indomáveis", ou um filme recente, como "Ainda estou aqui".
Os requisitos era conter imagens e estilos sobre os elementos usando usando o atributo 'style' e também usando as tags de formatação. Devendo conter pelo menos duas páginas "linkadas" entre si.
Utilizamos variações de cores, fontes, alinhamentos, tamanhos, etc.

Atividade 5: Listas e citações

Na Aula 6, construi um site com o tema: A evolução das tecnologias de redes de computadores (Tema que o professor exigiu).
Requisitos: pelo menos 3 páginas que possam ser "linkadas" entre si, utilizar imagens, citações e listas (ordenadas e não ordenadas). Além disso deve-se utilizar pelo menos uma definição de cores no formato hexadecimal.
