Minha Experiência com GitHub e Git

De inicio, tive certa dificuldade para mexer no GitHub - como colocar os arquivos, acessar meu site, interligar, criar um portfólio. Mas com o tempo, apredi e passei a utiliza-lo com facilidade.

Então veio o Git. Admito que estava tendo dificuldades mesmo assistindo aos vídeos, porque um falava e ensinava de um jeito, outra falava de maneira diferente, outro ainda enrolava um pouco para chegar no objetivo. Porém, a dificuldade encerrou quando o professor mandou um PDF mostrando o passo a passo de como clonar o portfólio e fazer o necessário básico.

Com o PDF, evitei de fazer certas coisas desnecessárias. Tornou prático e fácil usar, embora ainda terei que saber de cabeça futuramente - especialmente ao fazer em grupo.

Dificuldades encontradas

Além de ter que enteder a diferença entre eles (GitHub e Git), ter que usar os comandos no terminal, já que tenho uma leve dificuldade em interpletar direitinho por conta da minha lerdeza leve.

Como superei a dificuldade

Em uma única palavra: PDF

O PDF que o professor mandou ajudou MUITO. Foi mais fácil de entender, compreender e como fazer sem complicar (embora eu tenha uma suspeita que os vídeos também não eram complicados, o meu cérebro que não processava direito).

Conclusão

No final, consegui aprender um pouco a diferença entre eles, clonei meu portfólio do GitHub, criei uma nova página e, se der certo, fazer um commit e enviar as alterações para o GitHub.
